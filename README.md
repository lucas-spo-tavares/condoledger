# CondoLedger

CondoLedger is a web-based condo management system for tracking monthly contributions, manual payment registration, attached proofs, monthly expense logging, and PDF reporting.

## Scope

- OTP authentication for admins and residents
- Admin backoffice for resident and payment management
- Manual payment registration with image or PDF proof uploads
- Monthly expense tracking
- Monthly PDF report generation
- Optional QR code Pix payment instructions
- Resident portal with access restricted to personal data only
